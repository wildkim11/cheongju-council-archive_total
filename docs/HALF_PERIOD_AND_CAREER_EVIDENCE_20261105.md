# 전후반기 달력과 현재 프로필 경력 원문 검증

## 전후반기 경계

추가 공식 사이트 요청 없이 보존 회의록과 대수 루트 트리를 대조했다.
경계일은 각 회의록의 발언 문맥에서 확인하고, 양끝은 검증된 전체 임기로 제한한다.
일률적으로 2년을 더하거나 의장 선출일을 전후반기 시작일로 쓰지 않는다.

| 통합 대수 | 전반기 | 후반기 | 경계 근거 |
|---|---|---|---|
| 1대 | 2014-07-01~2016-06-30 | 2016-07-01~2018-06-30 | [728번, 2016-06-20](https://councilrec.cheongju.go.kr/minutes/svc/web/cms/mnts/SvcMntsViewer.php?schSn=728) 의사팀장의 전반기 종료/7월1일 설명 |
| 2대 | 2018-07-01~2020-06-30 | 2020-07-01~2022-06-30 | [2003번, 2020-07-01](https://councilrec.cheongju.go.kr/minutes/svc/web/cms/mnts/SvcMntsViewer.php?schSn=2003) 의장의 후반기 시작 첫날 발언 |
| 3대 | 2022-07-01~2024-06-30 | 2024-07-01~2026-06-30 | [3424번, 2024-07-01](https://councilrec.cheongju.go.kr/minutes/svc/web/cms/mnts/SvcMntsViewer.php?schSn=3424) 시장의 오늘 후반기 시작 발언 |
| 4대 | 보류 | 보류 | 확인된 경계 원문 없음 |

728번에는 의장 선출을 7월4일에 하는 일정과 후임 의장 선거 전날까지 전임의장이
직무를 수행한다는 설명도 함께 있다. 이 개인 직위 재임과 의회 전후반기 달력은 구분한다.
1대의 연도는 해당 회의일(2016-06-20) 문맥에 연결했고 다른 대수로 일반화하지 않았다.
전반기 시작/후반기 종료는 전체 임기의 양끝이며, 전반기 종료는 확인된 후반기 경계의
전날로 분할한 값이다. 각 반기 양끝이 모두 한 문장에 직접 적혀 있다는 뜻은 아니다.

`config/council_half_boundaries.json`에는 인용문·문자 위치·인용 SHA·발언자/역할·
회의록 ID/URL/파일 SHA와 해석 규칙을 보존한다. `council_half_periods.py`가 회의록
원장/메타데이터·공식 공개상태·전체 바이트/본문 SHA·정확한 인용 구간·발언자를
검증한다. 같은 의회/대수의 전체 임기 안에서만 양분하며 중복/역전/범위이탈/변조는
실패한다. `verified_council_periods.load_verified`를 통해 전체4+반기6=10행을 사용한다.
기간 근거가 하나라도 빠진 복합 선택은 전부 보류한다. HTML 필터 연결은 별도 과제다.

## 현재 프로필 경력 추출 오류와 정제 근거

기존 `_career_items`는 종료표식이 없으면 전체 HTML의 모든 목록을 경력으로 읽었다.
보존된 현재 의원 44명 배열 모두에서 실제 경력 목록 외의 항목이 확인됐다.
앞으로는 유일한 ‘경력사항’ 제목 바로 뒤의 목록만 추출한다. 제목/목록이 없거나
중복·비정상 중첩 구조이면 빈 결과로 보류하고 전체 페이지로 확장하지 않는다.

보존 프로필 응답 44개를 원장 SHA·응답 SHA/크기·프로필 코드/URL·제목의 의원 이름과
대조했다. 각 경력 목록은 추가 HTTP 없이 다시 읽어 다음 파생 보고서에 보존했다.

- `reports/current-career-evidence-latest.json`: 현재 프로필 44명/원문44버전,
  경력368항목, 번호를 붙인 의회 경력 언급69개. 이는 고유 재임 대수나 당선 횟수가 아니다.
- 기존 people 원자료와 그 경력 배열은 이번 오프라인 작업에서 덮어쓰지 않았다.
  다음 정상 의원명부 수집부터 수정된 파서가 정제된 경력 배열을 저장한다.
- 정제 보고서도 기존 인물의 귀속·인물 병합·선수에 자동 사용하지 않는다.
  `career_complete:false`, `seniority:null`, `seniority_filter_usable:false`를 유지한다.
- 정기수집의 게시 전 검증 및 오프라인 가공에 같은 경력 재검증을 연결했다.

## 비연속 선수 산정을 위한 다음 근거

1. 공식 개인의 당선 횟수 표기가 있으면 그 기준일·범위를 먼저 보존한다.
2. 산정하는 경우 당선 사건과 재임 대수 수를 별도 지표로 두고, 일반/보궐 당선 사건의
   고유 ID·당선일·공식 출처·대수·의회 범위와 동일인 연결 근거를 갖춘다.
3. 1대와 3대 당선은 중간 공백과 무관하게 별개의 당선으로 세되, 미관찰 2대를
   낙선으로 단정하지 않는다. 동일 선거의 여러 위원회·반기 경력은 중복 집계하지 않는다.
4. 통합의회 안의 경력과 통합 전 청주시/청원군 포함 경력을 구분한다.
   ‘제3대 청주시의회’ 같은 문구만으로 통합 전후 범위를 자동 확정하지 않는다.
5. 분석기간과 선수 기준일을 분리한다. 선택기간 중 관찰된 대수 수를 전체 선수로
   대체하거나 현재 프로필의 경력을 과거 시점에 소급하지 않는다.
6. 불완전한 약력·현재 명부·사진 일치만으로 완전 경력/동일인을 승인하지 않는다.
   근거 부족이면 선수는 미확정이며 0선/초선으로 대체하지 않는다.
