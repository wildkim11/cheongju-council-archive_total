# 청주시의회 의안 발의자 확인을 위한 원천자료 제출요구안 (2026-11-02)

**제출 요청처:** 청주시의회사무국 의사팀(의안 접수·보존 담당 부서, 실무상 담당 확인 필요)
**목적:** 통합 청주시의회 의안 데이터의 대표발의자 및 공동발의자 전원 실명, 원안·철회 이력과 기관제안 의안의 사람 이름 기재 의미를 공식 원천문서로 검증하기 위함.

## 요청 공통사항

아래 의안별로 가능한 범위에서 다음 자료를 **원형 파일(HWP/HWPX/PDF 등)과 의안관리시스템의 구조화된 명단**으로 제출해 주시기 바랍니다.

1. 의안 **원본 발의서(원안 접수본)**, 대표발의자와 공동발의자 **전원의 성명**, 총 발의 인원, 직위·발의 역할. 서명·날인 그림이나 연락처·주민등록정보 등 확인에 불필요한 개인정보는 가려도 무방하며, **의원 성명 및 역할은 보존**해 주시기 바랍니다.
2. 의안접수대장 또는 전자회의시스템에서 해당 의안번호로 조회한 **접수·반려·보류·회부·철회·종결 기록**(각 날짜 및 처리 유형 포함).
3. 발의자 변경·철회서·대표발의 변경 문서가 있다면 **원안과 변경안의 관계**와 각 시점의 발의자 명단.
4. 의안 상세 공개 페이지의 '대표발의자', '공동발의' 칸이 비어 있거나 다른 의안 상태값이 혼입되는 경우 해당 **원본 데이터 필드의 정확한 값**과 표시 누락 또는 인코딩 사유.
5. 모든 자료에 **대수, 회기, 의안번호, 내부 식별번호, 접수일, 작성기관, 파일명, 자료기준일**을 함께 표기하고, 명단이 없는 경우에는 **원자료 미존재/보존기간 만료/공개사이트 누락/비공개 등 사유**를 구분하여 회신 요청.

**동일 제목 혼동 방지**
- 1308·1458·2083·2364·2637은 유사/동일 제목 출석요구안이다. **의안번호, 회기, 대수, 접수일을 반드시 모두 매칭**해야 한다.
- 3255는 **2025년 제98회 의원발의 후 철회 의안**이며, 2024년 제91회 같은 제목의 **시장 제출·수정가결 의안과 다르다**.

### D. 데이터 이용 및 보존 원칙

- 원본 의안·회의록 파일과 기존 11,421행 인명관계는 삭제하지 않습니다.
- 정식 확인 전까지 명단 미확인 7건을 유지하고, 기관발의 5건에 연결된 44행은 의원발의 통계에서 격리합니다.
- 공식 증빙이 확보되면 출처·접수일·원문 파일 해시와 함께 의안별로 검증하고, 다른 의안 및 기존 데이터를 건드리지 않는 방식으로 보완합니다.
- **원안의 발의자**, 심사 중 **보고자·참석자·찬성표를 던진 의원**, 이후 **철회한 사람**은 서로 별개 개념입니다.
