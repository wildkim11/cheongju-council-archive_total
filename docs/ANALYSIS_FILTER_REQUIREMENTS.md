# 분석 조건 요구사항 — 2026-11-04 사용자 지시

## 대상 집단과 기간을 별도 조건으로 조합

초선·재선·3선 이상, 연속 재임과 중간 대수를 건너뛴 비연속 재임을 구분한다.
재선 이상을 고른 뒤 특정 대수의 전반기 또는 사용자가 지정한 날짜 구간만 분석하는
조합을 지원해야 한다. 선수·전체 재임 이력·이번 분석 기간을 같은 필드로 취급하지 않는다.

## 데이터 계약과 미확정 사항

- 대수별 프로필ID를 영속 인물ID와 연결한 검증 이력이 필요하다. 동명이인·이름 일치만으로
  합치지 않는다. 현재167프로필은167고유인물이라는 뜻이 아니다.
- 선수는 중복된 재임행 수가 아니다. 당선/재임 사건과 대수별 중복을 제거하고, 중간
  낙선·불출마 후 복귀도 포함한다. 보궐선거·중도사퇴 등 부분 재임은 별도 기록한다.
- 통합 이전 청주시·청원군 재임을 포함하는 선수와 통합 청주시의회 내 선수는 범위를
  명시해 구분한다. 이전 이력 미확보를 초선으로 단정하지 않는다. 전체 경력 기준인지
  선택 시점까지의 선수인지도 표시한다.
- 기간 선택: 시작일/종료일 직접 지정(양 끝 날짜 포함), 단일 대수, 복수 대수,
  대수별 전/후반기. 여러 대수는 구간들의 합집합으로 처리하며 중간 공백을 포함하지 않는다.
- 대수는7월 전환을 반영해 달력연도와 구분한다. 공식 대수별 개시/종료 기록을 보존하고
  보궐·사퇴·취임 등 개인의 실제 재임 구간과 교차해 분석한다.
- 전/후반기는 공식 기간 근거를 관리한다. 의장단·위원회 개편의 실제 효력일이 다른 경우
  그 이력을 따로 보존한다. 일률적인 날짜를 사실로 생성하지 않는다.
- 당시 정당·위원회·직책·지역구와 실제 재임일수/의안·발언 관찰기회를 함께 연결한다.
  현재 소속을 과거 전체 기간에 소급하지 않는다.
- 범위가 확정되지 않은 기간·귀속은 보류와 사유를 표시한다. 수집 범위와 실제 재임 범위를
  구분하고, 단순 건수를 활동성·성과의 우열로 바로 해석하지 않는다.

## 구현 순서와 검증 기준

1. 인물 교차표와 재임·당선·대수·전후반기 근거 원장을 먼저 검증한다.
2. 기간 해석 모듈은 불연속 재임·7월 경계·전후반기·보궐·사퇴·윤년·단일일자·역전 기간·
   중복 구간·이력 미확정 사례를 시험한다.
3. HTML에서 조건 조합과 현재 적용 범위/분모/수집 누락을 한눈에 표시한다.
4. 의원 요약·관계망·지역 지도·정당 비교에서 같은 조건 해석을 공유하고 원문까지 추적한다.

이 문서는 요구사항을 확정해 보존하는 단계다. 선수 필터/날짜 직접선택/복수대수/
전후반기 필터는 아직 구현 완료로 표시하지 않는다. 첨부본문 처리와 원장 검증을
진행하면서 해당 데이터 계약을 갖춘 뒤 구현한다.
