  낙선·불출마 후 복귀도 포함한다. 보궐선거·중도사퇴 등 부분 재임은 별도 기록한다.

  명시해 구분한다. 이전 이력 미확보를 초선으로 단정하지 않는다. 전체 경력 기준인지
  선택 시점까지의 선수인지도 표시한다.
- 기간 선택: 시작일/종료일 직접 지정(양 끝 날짜 포함), 단일 대수, 복수 대수,
