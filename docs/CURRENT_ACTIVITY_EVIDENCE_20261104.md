## 표시·갱신 계약

- 의안 사건 키: 의회범위 + `bill:대수:내부번호`. 같은 번호라도 다른 대수는 분리.
- 참여행: 고정 인물ID·역할·원장 데이터셋·1기준 행 번호. 이름만으로 연결하지 않음.
- `CouncilCountsUpdates.expand/validate`를 거친 eligible만 소비. held는 제외.
- 동일 사건의 날짜·공식URL·제목·범위·대수가 충돌하거나 참여가 중복되면 표시 중단.
- 최신 의안·활동 목록에 공식 원문과 고정 커밋 원장 행 링크를 제공.
- 공동참여는 같은 대수/의회범위의 동일 의안에 포함된 참여행의 동시등장 횟수.
  대표/공동 역할을 각각 제시하고 보류행을 뺀 명부가 공식명부 전체와 다를 수 있음을 안내.
- 인명순 표시·건수와 선택 의안 분모·가로 meter·해당 근거 목록 이동 제공.
- 개인판은 타 의원의 최신 참여행을 포함하지 않으므로 공동참여 비교 불가로 표시.
- 기존 집계 확인→검증→적용→새 HTML 저장 경로를 소비. 집계 객체가 바뀔 때 캐시 재검증.
- 과거 release-bundle/관계망을 합치거나 최신으로 승격하지 않고 접힌 영역에 보존.
