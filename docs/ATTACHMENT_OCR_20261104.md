# 한국어 OCR 후보자료 자동처리 — 2026-11-04

## 범위와 해석

보존된 JPG14개와 PDF기본추출문이 비어 있던7쪽, 합21대상이 이번 OCR범위다.
한국어+영어 Tesseract를 사용하고 이미지1쪽/PDF1기준 쪽좌표를 구분한다.
기본 PDF추출문122쪽을 덮어쓰거나, 나머지 쪽의 부분 누락까지 모두 탐지한 것은 아니다.

21대상 모두 OCR 후보 문자열이 생성됐으나 읽을 수 있는 본문21건이 확정됐다는 뜻이 아니다.
표본 대조에서 포스터의 글자 누락/오인식과 사진의 선·무늬를 글자로 오인하는 사례를
확인했다. 특히 사진 위주 PDF쪽은 의미없는 기호가 생성될 수 있다. 전부
`machine_ocr_unreviewed`, `semantic_verified:false`, `member_attribution_allowed:false`,
`analysis_usable:false`로 보존한다. 사람검토0·의미검증0을 유지한다.

주최/참석자 표기를 의원의 저술·발언·관심 주제로 승격하지 않는다. 단어별 Tesseract
신뢰도는 엔진 출력이며 정확도·정책분석 점수가 아니다. 실제 정확도는 정답 전사와
별도 대조하기 전에는 계산하지 않는다.

## 증거·처리 계약

- 원본 큐/파일SHA·경로·크기·형식, 기본추출문 manifest/gzip/쪽번호·본문SHA·추출기
  기준을 먼저 검증한다. 저장소 밖이나 다른 원문을 대신 읽지 않는다.
- 한글 모델이 없으면 영어만으로 대체하지 않고 처리기를 중단한다.
- 한국어/영어 traineddata의 SHA, Tesseract/Poppler/Pillow 버전, 코드SHA,
  PDF DPI200·최대변3000·PSM11/OEM1·EXIF회전/회색조/자동대비 전처리를 기록한다.
- 전처리된 래스터의 크기·픽셀SHA, OCR텍스트SHA, 단어별 좌표·엔진 신뢰도를 보존한다.
  단어 좌표는 이 전처리 래스터 기준이며 원본 인쇄면수/원본 픽셀좌표와 구분한다.
- 출력은 `exports/attachment-ocr/manifest.json`과 원본SHA-쪽별json.gz,
  `reports/attachment-ocr-latest.json`. 기본추출문과 별도로 보존한다.
- 결과가 같은 원본/쪽·엔진/모델/코드이면 해시를 검증해 재사용한다. 출처 제목·원장SHA만
  바뀌면 검증된 OCR결과는 재사용하고 참조정보만 갱신한다.
- 오류는 ocr_error_held, 회차 한도초과는 ocr_pending, 무문자 출력도
  ocr_no_text_unreviewed로 기록한다. 무문자=빈쪽 확정이 아니다.
- 한 번에 최대24대상, 이미지40M픽셀/출력최대변3000, 렌더/인식 시간 및 출력크기 상한을
  둔다. 오류자료는 `--retry-errors`로 선택 재처리한다. 모델/엔진 변경은 새로 처리한다.

## 자동화와 검증

기존 `process-attachment-text.yml`의 기본추출 뒤에 OCR처리를 추가했다. 한국어/영어
모델과 Pillow를 준비하며 공식사이트 HTTP요청은0이다. 공식 수집 macOS경로·일일수집/
실패전용 재시도 정책은 변경하지 않는다. OCR출력 자체가 새 수집 실행을 유발하지 않는다.

```sh
python scripts/ocr_attachment_pages.py
python scripts/ocr_attachment_pages.py --tessdata-dir /path/to/tessdata
python scripts/ocr_attachment_pages.py --retry-errors
```

전체511시험(기존499+신규12)을 수행했다. 한국어 모델을 갖춘 로컬 실행에서 전부통과.
원본/캐시 변조·쪽/텍스트SHA·단어 경계/신뢰도 범위·한글모델 누락·재사용·참조정보만
갱신·오류선택재시도·회차한도·귀속/의미승격 금지를 확인했다. 별도 모델 디렉터리에
txt/tsv 설정파일이 없어도 명시적 출력옵션으로 두 결과가 생성되는 실제 회귀시험도 포함한다.

21대상의 실제 결과는 원본/페이지 증거와 별도 미검토 자료로 저장한다. 사진/포스터
표본 시각 점검은 전체 정답검수나 사람 검토완료로 승격하지 않는다.
