## 3. 저널의 명시적 삭제 정책

일반적인 staging 결과에서 파일이 누락됐다는 사실만으로 실제 원본 삭제를 추론하지 않는다.

**오직 수집기가 공식 동일 `meeting_id/source_id`의 저장 경로 이동을 확인하고 이전 원본을 불변 이력에 보존한 경우**에만 이전 canonical 경로를 명시적 `removals` 목록에 넣는다. 저널 삭제 허용 경로는 `archive/meetings/cheongju_integrated/term-N/YYYY/minutes-X.md` 구조로 제한한다.

저널 manifest는 해당 파일의 `old_exists=true`, `old_sha256`, `new_exists=false`를 명시한다. 저널 봉인 이전에는 정식 경로를 건드리지 않으며, SIGKILL 뒤 재시작에서 커밋 표식이 없으면 이전 경로를 원래 바이트로 복구한다. 커밋이 확인되면 새 경로와 구 파일의 부재를 함께 검증한다.

*제한:* 이것은 로컬 POSIX 환경의 SIGKILL과 정상적인 예외를 검증한 것으로, 물리적 전원 장애·네트워크 파일시스템·비협조적 외부 작성자의 내구성을 보증하지 않는다.
