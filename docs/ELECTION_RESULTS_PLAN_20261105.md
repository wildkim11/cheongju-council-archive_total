이 문서는 계획이며 선거구별 전체 결과 수집·정렬 화면이 구현됐다는 뜻은 아니다.

## 목표와 대상

각 의원의 대수별 선거결과를 공식 원문에 근거해 가능한 자세히 수집하고,
사용자가 원하는 조건과 순서로 정렬·필터·비교할 수 있는 선거결과 원장을 만든다.
선수 산정의 보조자료에 그치지 않고 독립적인 조회·비교 기능으로 관리한다.

현재 의원44명에서 확보한 선관위 이름검색 원문과 근거 기반 연결을 출발점으로 삼되,
현재 의원으로 대상을 고정하지 않는다. 통합의회1~4대와 현재·과거 의원의 연결 근거를
먼저 확장하고, 통합 전 청주시의회·청원군의회 경력과 재보궐을 범위별로 확대한다.
공개되지 않았거나 아직 검증하지 못한 항목은 확보 상태와 사유를 표시한다.

## 수집 항목

| 자료군 | 공개·확인되는 범위에서 확보할 항목 |
|---|---|
| 선거 사건 | 공식 선거ID·선거종류·회차·선거일, 일반/재보궐 구분, 의회 범위와 연결 대수 |
| 후보자 | 공식 후보 식별자(있을 경우), 이름, 기호, 당시 정당, 지역구/비례 구분, 공개 경력·학력 |
| 개인 결과 | 공식 당선 상태, 득표수, 공식 표시 득표율, 순위, 무투표 여부, 사퇴·사망·등록무효 등 별도 상태 |
| 선거구 전체 | 같은 선거구의 전체 후보자·각 결과, 후보자 수, 선출 정수, 마지막 당선자·첫 낙선자와 당락 경계 |

| 개인 이력 | 출마·당선·비연속 당선, 당시 정당/선거구 변화, 통합 전후·재보궐·기준일별 이력 |

당선자만 모으지 않고 비교에 필요한 상대 후보까지 같은 선거구의 결과로 수집한다.
같은 선거·선거구의 원문은 한 번 확보해 여러 의원의 비교에 재사용한다.
공식 후보자ID가 없는 자료에 이름만으로 영속 인물ID를 만들어 넣지 않는다.

## 자료 연결과 비교 기준

- 의회 대수와 지방선거 회차는 별도 필드다. 선거일이 임기 시작 전일 수 있고,
  같은 대수 안에 재보궐이 있으므로 단순 연도·7월 공식만으로 연결하지 않는다.
  공식 임기/선거 근거와 연결 사유를 보존한다.
- 선거구는 당시의 코드·명칭·구성 지역·선출 정수를 버전별로 저장한다.
  같은 이름이더라도 구역이 달라졌으면 같은 조건으로 취급하지 않는다.
- 지역구 중선거구제에서는 마지막 당선자와 첫 낙선자의 표차를 기본 당락 경계 지표로
  삼는다. 개인의 최다득표자 대비 차이·인접 순위 차이와 구분해 선택할 수 있게 한다.
  공식 당선 상태를 우선하고 동률·법정 처리·후보 상태에 따른 예외는 별도 검증한다.
- 기호(예: 1-가)·목록 순서·득표 순위를 혼동하지 않는다. 공식 순위와 계산한 순위는
  구분하고, 후보자 명부가 불완전하면 순위·당락 경계 계산을 보류한다.
- 득표율의 분모·유효투표 집계 범위를 보존하고, 비율 차이는 퍼센트포인트로 구분한다.
  공식 표시값과 원자료에서 계산한 값을 분리한다. 반올림 차이는 오차 범위를 명시한다.
- 비례대표의 정당 득표·명부 순위·배분 의석과 지역구 개인 득표를 같은 순위표에
  섞지 않는다. 무투표 당선의 득표/표차는 0으로 만들지 않고 해당 없음으로 표시한다.
- 미수집·미확인·해당 없음·공식 0값을 구분한다. 후보자 기록만 있거나 당선 표시가
  없다는 이유로 낙선 판정을 만들지 않는다. 당시 정당을 현재 정당으로 덮어쓰지 않는다.
- 최소 확인 당선 수·정확한 전체 선수·특정 기준일까지의 선수·선택기간의 재임 대수 수를
  구분한다. 인물 연결/이력 미확정을 초선이나 비교 제외의 근거로 쓰지 않는다.

| 기능 | 목표 동작 |
|---|---|
| 정렬 | 선거일·대수·의원명·당시 정당·선거구·당선 상태·득표수·득표율·순위·당락 표차의 오름/내림차순 |

선거결과를 좁히는 날짜(선거일)와 의정활동 분석기간(재임일/발언일)은 별도 조건이다.
사용자 조건을 공통으로 관리하고 의원 요약·관계망 등 기존 분석과 연결할 때 그 차이를
명시한다. 선거구·정수·분모가 바뀐 선거끼리의 단순 순위는 우열 평가로 바로 해석하지 않는다.

## 구현 순서와 완료 기준

1. **원장 설계·수집 범위 점검**: 현재 인물 연결 검증과 병행해 선거/선거구/후보/결과의
   식별키, 원문 출처, 항목별 확보 상태 및 대수 연결 계약을 정리한다.
2. **공식 상세 결과 수집**: 이름검색 요약에서 관련 공식 선거·선거구 전체 결과로 확장한다.
   원문 보존·중복 요청 방지·실패/제한/재시도·검증 보고서를 기존 운영 원칙에 맞게 설계한다.
   계획 추가만으로 정기 조회나 새로운 외부 요청을 즉시 시작하지 않는다.
3. **인물/범위/지표 검증**: 동명이인·통합 전후·재보궐·선거구 개편·지역구/비례·무투표·
   동률·미확인·낙선/사퇴/무효 상태와 표차/득표율을 대조한다. 완전성 확인 후 비교 지표를 계산한다.
4. **표 기반 기능 연결**: 다중 정렬·복합 필터·개인/복수 의원/선거구 비교와 원문 이동을
   구현한다. 미확정 포함 여부, 수집 범위, 기준일, 분모와 선출 정수를 함께 표시한다.
5. **시각화·내보내기**: 검증된 표와 같은 결과가 나오는 것을 확인한 뒤 추이·비교 시각화와
   파일 내보내기를 연결한다. 기존 심사·분석 기능과 개인판 보호 원칙을 유지한다.
