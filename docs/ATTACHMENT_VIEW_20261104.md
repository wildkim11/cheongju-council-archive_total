# P07 첨부 원문·쪽별 추출문 HTML 연결

마스터의 활동 화면에서 공통 첨부 목록을 열고 PDF쪽별 텍스트·출처·자동추출 상태를
확인할 수 있게 연결했다. 현재 기준 자료는
`f787b3533e4c8a107ef3c77869f6c06f941808e6`의 첨부 배포다.
기존 활동/집계 기준 `f978de20298e357f21a5e3c87d4b616d1a3339be`와 별도로 표시한다.

## 표시 범위

- 보존18파일 중 PDF4개129쪽: 텍스트122쪽, 텍스트미추출7쪽. 이미지14개는 OCR대상.
- 추출문은 자동추출·미검토이며 사람 의미검증/의원 귀속/관심 분석 입력으로 승격하지 않는다.
- 공통 토론회 자료를 선택 의원·대수의 개인 활동과 혼동하지 않도록 표시한다.
- 개인판은 전체 공통 첨부목록을 표시/조회하지 않는다. 원래 포함된 개인 활동의 첨부
  링크 기능은 기존 별도 모듈을 유지한다.
- PDF쪽 선택·이전/다음·쪽별TXT, 공식첨부·게시물·고정 보존파일 출처를 제공한다.
- 원본PDF를 별도로 불러올 때 바이트SHA/크기/헤더를 검사한 후 PDF Blob을 제공한다.
  PDF뷰어의 실제 쪽이동은 브라우저 지원에 의존하며 인쇄면수와 다를 수 있다.
- 미추출쪽은 OCR/원문대조 필요로 표시한다. 빈페이지·활동없음으로 판정하지 않는다.

## 검증·갱신 계약

내장하는 것은 고정 커밋과 목록SHA descriptor뿐이다. 목록·원본큐·원장 manifest·
추출기 일치, 파일/쪽수·미검토 플래그·쪽번호·쪽별 해시를 검증한다.
크기/압축해제 상한이 있으며 해시/참조 오류는 해당 표시를 중단한다.
닫힌창에 늦은 응답을 적용하지 않는다. PDF Blob 주소는 교체/닫기 후 지연 해제한다.

새자료 확인 시 HEAD고정→compare→배포자료 검증을 거친다. 과거/분기버전·기존URL
삭제/원본SHA변경은 자동 적용하지 않는다. 확인만으로 descriptor를 바꾸지 않고,
명시적 적용과 새HTML 저장 요청 준비를 거쳐 갱신한다. 활동/회의록/집계 버전을
덮어쓰지 않는다. 본문은 열람할 때 GitHub 연결이 필요하다.

## 완료 검증

- 전체499시험(기존494+신규5) 통과. Node reader10사례에서 실제129쪽을 검증하고
  목록누락·원장좌표·위험경로·gzip/본문/쪽번호 변조·의미승격·원본변조·역행을 차단.
- 설치기는 중복/손상 구조를 거부하며 과거 JSON에 포함된 이스케이프 HTML시안을
  실제 release 태그로 오인하지 않는다. 관련 회귀시험 추가.
- jsdom26.1.0에서 마스터/개인 각각7그룹24화면, 기존4내장JSON 동일성을 확인.
- PDF4개129쪽 전부 이동·TXT해시/링크 검증, 미추출7쪽 표시, 원본4PDF 바이트해시·
  PDF MIME·쪽fragment를 확인. UI 준비를 확인했으며 네이티브 PDF렌더링 검증은 아니다.
- 합성 메타데이터 변경으로 새자료 확인/적용/저장HTML 재실행을 시험했다.
  합성 자료는 최종 배포HTML이나 저장소 데이터에 기록하지 않았다.
- 개인판 공통목록 차단·닫기 경합 방지·저장재실행을 확인했다. 공식사이트 HTTP0.

## 남은 작업

실기기 CORS/PDF뷰어/다운로드/모바일, 이미지14개·미추출7쪽 OCR와 원문대조,
첨부1873URL의 대기/크기보류 처리, 보류487활동·개인판 공동사건 범위·수집의 일일
반복관찰이 남는다. 선수·비연속재임·날짜범위·대수·전후반기 요구는 기존 명세에
유지하며, 관련 원장 검증과 필터구현을 완료로 표시하지 않는다.
