# Historical research-group source strategy

Historical research-group relationships are promoted only from official sources that print a full participant roster.

Source families:
- annual research-group composition notices
- official research-group overview tables
- annual research-activity report pages
- linked official report attachments when roster verification is required

## Promotion rule

A source can create a research-group membership relation only when:
- the group name is explicit;
- the full participant list is explicit;
- the representative is identifiable when printed;
- printed member count matches parsed participants when a count is stated;
- member names can be resolved within the correct council term.

A notice/report that names only the registered groups, without participants, is source metadata only.

Large report attachments are not mirrored by default. Their official link and source identifier are retained. A linked attachment may be inspected for roster verification without becoming a permanent mirrored binary.
