# 의회 대수·전후반기 공식 원문 수집 및 검증

공식 명부 보존 응답의 실제 메뉴 링크에서 다음 세 경로를 확인했다.

- https://council.cheongju.go.kr/content/council/history.html — 의회연혁
- https://council.cheongju.go.kr/content/member/memberMission.html — 의원임무/임기
- https://council.cheongju.go.kr/content/council/configuration.html — 구성표

`collect_council_period_sources.py`는 GitHub macOS에서 위 세 페이지만 순차 GET한다.
요청당 1회·재시도 없음·30초 제한·최대 2MiB이며 첫 실패에서 중단한다.
원문 UTF-8 응답을 공통 content-addressed 보관소와 해시 원장에 보존한다.
부분 성공도 그대로 기록하고 의회 전체 임기·전후반기·개인 선수로 승격하지 않는다.
정기수집과 같은 실행 그룹에서 직렬화해 공식 사이트 조회의 중복 실행을 제한한다.
공식 사이트의 조회는 macOS에 한정하며 Ubuntu는 보존된 응답만 검증한다.

`audit_council_period_sources.py`는 대응 응답 원장의 해시·스키마와 원문 경로·크기·해시를
확인한 뒤 날짜·대수·전후반기·임기 언급의 HTML 행/열과 앞뒤 문맥을 추출한다.
메뉴·의장 재임·역사적 사건 날짜도 포함될 수 있으므로 모든 언급은 검토 대상으로만 둔다.
스크립트·스타일·주석 문구는 제외한다. 메뉴 언급이나 개원일만으로 기간을 추가하지 않는다.

## 실제 확인 결과

세 페이지는 모두 수집됐다. 연혁은 통합 1대 2014-07-01·2대 2018-07-03·3대
2022-07-04의 **개원일**을 표시한다. 의원임무/임기는 일반적인 4년 임기와 보궐임기
원칙을 설명하며, 구성표에는 날짜 없이 현재 위원회 명단이 표시된다.
따라서 이 세 페이지에서 대수 전체 또는 전후반기 기간을 만들지 않았다.

별도로 이미 보존된 공식 회의록 루트 트리 응답 두 버전에서 아래 날짜를 직접 확인했다.
`verified_council_periods.py`가 응답 원장·원문 크기/SHA·노드 위치·대수코드·표시 문구를
재현하고, 두 버전의 날짜가 충돌하면 실패한다. 이 근거에 한해 기간 레지스트리 4행을
활성화했다. 날짜 공식이나 개원일에서 계산한 값이 아니다.

| 통합의회 대수 | 공식 표시 시작일 | 공식 표시 종료일 |
|---|---|---|
| 1대 | 2014-07-01 | 2018-06-30 |
| 2대 | 2018-07-01 | 2022-06-30 |
| 3대 | 2022-07-01 | 2026-06-30 |
| 4대 | 2026-07-01 | 2030-06-30 |

4대 종료일은 공식 표시된 전체 임기이며 이미 경과한 재임이나 활동기회가 아니다.
전후반기·통합 전 두 의회는 여전히 등록하지 않았다. HTML 조건 연결도 미완료다.

추가로 공식 회의록 728번(2016-06-20)에는 전반기 6월 30일 종료/후반기 7월 1일
시작 설명과 7월 4일 의장 선출·전임의장의 권한 연장 설명이 함께 있다.
전후반기 달력과 의장 개인 재임을 구분해야 하며, 다른 대수에 일반화하지 않는다.
원문: https://councilrec.cheongju.go.kr/minutes/svc/web/cms/mnts/SvcMntsViewer.php?schSn=728

정기수집 게시 전 검증과 오프라인 자동 가공에도 같은 검증기를 연결했다.
새 시험은 macOS 외 실행 거부·요청 상한·첫 오류 중단·기존 해시 충돌 보호·원문/원장
변조·경로이탈·한국어 위치/문맥·누락 원문·외부 URL 격리를 확인한다.
실제 소스 수집 완료 여부는 `reports/council-period-source-collection-latest.json`과
Actions 결과를 확인한다. 수집 완료와 공식기간 확정은 다른 상태다.

선수는 낙선 등 공백을 끼운 재임도 포함할 수 있어 연속재임 횟수로 대체할 수 없다.
통합 전 의회 포함 범위·선택 시점·공식 당선/재임 이력의 완전성·동일인 연결 근거를
갖춘 뒤 산정한다. 반복 프로필 코드만으로 병합하거나 미관찰 대수를 낙선으로 판정하지 않는다.
