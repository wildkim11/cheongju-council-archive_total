## 이번 화면의 역할

원문 기반 전처리 이미지와 OCR 후보/수정문을 나란히 보여준다. 왼쪽은 OCR와
동일한 회색조·축소 이미지이며 색상 원본 파일 자체가 아니다. 공식 첨부·고정원본
링크를 별도로 제공한다. 단어/상자 선택, 확대, 대상 이동을 지원한다.

이미지/쪽·텍스트·단어 좌표는 고정 원본SHA·OCR문서SHA·전처리 픽셀SHA에 연결한다.
렌더 환경 차이로 픽셀이 다르면 자산 생성을 중단한다. 현재 환경에서 비슷하게
그려졌다는 이유로 기존 단어 좌표를 덮어 씌우지 않는다. GitHub OCR와 같은 가공
환경에서 검토 PNG를 만들고 파일·픽셀 해시를 검증해 보존한다.

## 검토 상태와 보존

- 미검토 / 수정초안 / 전사 대조기록 / 보류. 초깃값은 모두미검토이며 사람검토0.
- 전사 대조기록은 검토자·이미지 전체 대조 확인·전사문이 있어야 남길 수 있다.
  보류는 검토자와 사유가 필요하다. 사진/도형 오인식도 보류할 수 있다.
- 수정문·사유·검토자 변경 시 기존 대조 확인을 해제하고 초안으로 되돌린다.
- 전사 대조기록도 의미검증·정답자료·의원 귀속·분석승인이 아니다. 내보낸 모든 행은
  analysis_usable:false / semantic_verified:false를 유지한다.
- OCR원래 문자열은 고정해 보존하며 수정문을 별도 필드에 쓴다. 단어별 엔진값은
  정확도/정책점수가 아니다.
- 브라우저 임시보관과 JSONL·전체JSON 백업/불러오기를 지원한다. 버전·원본·OCR·
  픽셀 해시가 다른 기록, 중복ID·부분손상은 일괄 미적용한다. 불러오기 되돌리기 제공.
- 검토자의 입력은 기기 내부와 사용자가 저장한 파일에만 남는다. 저장소 전송이나
  분석 자료에 자동 반영하는 동작은 없다. 재열기 보존은 브라우저 환경에 의존하므로
  파일 백업을 기본으로 안내한다.

## 자동화와 파일 생성

`build_ocr_review_assets.py`는 검증한 OCR결과에 대응하는 PNG/manifest를
`exports/attachment-ocr-review`에 보존한다. 기존 오프라인 처리 작업의 OCR 뒤에서
자동 실행하고, 같은 작업에서 커밋된 자료를 기반으로 검토 HTML을 Actions artifact로
내보낸다. 기본추출문/공식수집 경로를 변경하지 않는다.

```sh
python scripts/build_ocr_review_assets.py
python scripts/build_ocr_review_packet.py --source-commit COMMIT_SHA --output /tmp/OCR_review.html
```

검토파일은 고정 커밋의 manifest/PNG/OCR문서를 대조해 만든 독립 HTML이다.
이미지까지 내장하므로 검토·저장에 네트워크가 필요 없고, 공식 원문 링크를 열 때만
별도 연결이 필요하다. 현재 전체분석 마스터/개인 HTML은 변경하지 않는다.
