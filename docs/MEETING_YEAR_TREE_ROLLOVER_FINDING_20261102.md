## 핵심 확인 사실: 연도가 바뀐 뒤 열린 전년도 회기의 위원회
1. **13건 모두** 제목상 회기 종료일은 **전년도 12월**, 실제 회의일은 **다음 해 1~2월**이다.
2. 13건 실제 회의일은 1월 8건, 2월 5건. 본래 회기 종료일보다 **27~49일 후**에 열렸다.
3. 회기 종료 후 개최된 다른 회의록 중 연도별 목록에도 있는 **108건은 모두 동일 연도 안의 회의**였다. 이들의 회기 종료 후 경과기간은 1~76일이다.
4. 대수별만 있는 13건 중 의회운영위원회 `committee_code=C101` 12건, 미세먼지 행정사무조사특별위원회 `G220` 1건. 비교군 108건 중 같은 `C101` 유형은 80건, 같은 `G220` 유형도 11건 존재한다.
5. 따라서 **회기 종료 후 개최** 및 **위원회 구분**만으로는 목록 차이를 설명할 수 없으며, **회기 종료연도와 개최연도가 달라지는 조건**이 현재 2,339건 저장자료에서 13건을 정확히 구분한다.

## 실시간 서버 검증 범위
1. 공식 트리 엔드포인트 `SvcMntsTreeYear.php`, `SvcMntsTreeGnrtn.php`에 읽기 전용 POST 요청. 연도별 최상위 노드 13개(연도), 대수별 4개(대수), 하위 표본을 조회했다.
2. 공식 뷰어 `SvcMntsViewer.php?schSn=180`, `1848`, `3652` 직접 GET 성공. 실제 HTML 내 회의록 본문 표식과 회의일 텍스트 존재 확인. 원문 바이트·SHA-256은 GitHub Actions artifact에 기록했다.
3. 최초 대량조회는 접속 제한시간 경과로 실패했다. 첫 소량 조회는 SSL 오류였으나 기존 수집기와 동일한 TLS cipher 설정 `DEFAULT` 적용 뒤 **8개 트리 요청·3개 뷰어 요청 전부 성공**했다. 그러므로 '공식 홈페이지 서버가 다운됨'이라는 단정은 틀리다.
4. 조회 성공 사실 자체가 13건의 연도별 검색 분류 규칙을 공식적으로 확정해 주지는 않는다. 루트-회기-위원회-원본 ID에 이르는 실제 두 트리 경로 결과를 별도 보고한다.

## 자료 이용 원칙
- 회의록별 대수·날짜·공식 URL은 **대수별 원본 트리**와 기존 공식 개별 뷰어를 기준으로 유지한다.
- 분석기는 회의록 2,339건 모두를 이용한다. 연도별 트리 전용 검색에만 의존하면 13건이 제외될 수 있다.
- 13건을 '진짜 원본 누락' 또는 '삭제된 회의록'으로 단정하거나 자료를 임의 재편집하지 않는다.
- 연도 경계가 실제 웹사이트 내부의 어느 SQL 조건/트리 필터에서 발생하는지는 서버 구현자료 없이는 확정할 수 없으며, 공개 두 트리 결과로 판별 가능한 **관측된 현상**과 **내부 원인 추정**을 구분한다.
