# 통합 전후 의원 선거이력 대조

의회 공식 명부의 통합 전후 검토 대상 이름 20개를 선관위 공개 후보자·당선인 검색과 대조했다. 구 청주시 명부와 통합 명부에 함께 나타난 이름이 15개, 청원군 명부와 통합 명부에 함께 나타난 이름이 5개다.

검색 응답 20건을 보존했다. 기존 원문 2건은 URL·크기·해시를 검증해 재사용했고, 18건을 추가 확보했다. 20건 모두 파싱했다. 전체 검색에서 후보·당선 이벤트 220건을 분리했고, 이 중 청주·청원 기초의원 당선 탭 및 당선 표시를 함께 확인한 행은 62건이다. 아래는 해당 당선행의 선거일이며 2014-06-04는 통합 청주시의회 선거로 분류했다.

19개 이름에서 두 시기의 당선행이 동일 선관위 인물 묶음에 있다. 김병국은 2014년 선관위 공개 경력에 청원군의회 1~3대 의원이 명시돼 의회 명부와 부합한다. 통합 전 각 선거의 당선 원문을 확보할 때까지 해당 선거일·당선 횟수는 보류한다. 최진현의 2012년 당선은 선거일을 그대로 보존해 정기 지방선거 사이의 당선 기록도 비교할 수 있게 했다.

선관위 검색 인물 묶음은 자료 대조 단위다. 의정분석툴 인물 ID와 재임기간 연결은 개별 근거 확인 뒤 반영한다. 당선행이 없는 연도는 미확인으로 처리한다. 통합 1~4대 명부에서 네 대수 모두 같은 이름이 나온 김은숙·남일현·박노학·정태훈은 별도 검토 대상으로 유지한다.

원문 위치·해시·공개 경력·당선 표시 근거는 [수집 목록](../reports/nec-legacy-bridge-collection-latest.json)과 [파싱 검증 결과](../reports/nec-legacy-bridge-audit-latest.json)에 있다.
