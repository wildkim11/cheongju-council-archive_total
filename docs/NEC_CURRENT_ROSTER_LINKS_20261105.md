# 현재 의원 44명 선관위 조회와 근거가 일치한 선거 이력 연결

## 수집과 원문 검증

현재 의원 명부 원문과 프로필의 코드·이름을 대조한 44명을 조회 대상으로 삼았다.
기존 3명 표본은 바이트·SHA·정확한 GET URL을 재검증해 재사용하고, 나머지41명만
GitHub macOS에서 각1회 조회했다. 재시도0·이름당1회·응답8MiB상한·요청간1초이며,
연속3오류 시 남은 요청을 중단하는 제한을 두었다. 실제41요청은 모두 성공했다.

44개 원문 총7,911,331바이트를 보존했다. 파싱 보류0이며 동명이인·다른 지역을 포함한
후보/당선 사건321개 중 청주·청원 기초의원 사건83개, 당선 표시75개를 확인했다.
이75개를 현재 의원의 당선 횟수로 합산하지 않는다. 같은 이름의 다른 사람일 수 있다.
수집 완료는 **44개 이름검색 원문 확보**이며 모든 의원의 완전한 당선 이력 확보와 다르다.

원문: `archive/elections/nec/source_responses`.
수집: `reports/nec-current-roster-collection-latest.json`.
검증: `reports/nec-current-roster-audit-latest.json`.
수집 workflow는 최초 완료 후 수동 실행만 가능하다. 이 경로는 정기 최신화가 아닌
제한된 증분 스냅샷이며, 재실행 시 검증된 기존 원문을 재사용한다.

## 현재 의원과 연결하는 조건

`link_nec_current_profiles.py`는 아래 조건이 모두 충족되는 하나의 선관위 인물 묶음에만
현재 프로필의 선거 사건을 연결한다.

1. 의원의 현재 공식 프로필 제목·이름·정확한 URL/코드와 현재 공식 명부의 이름/URL이 일치.
2. 검증된 통합4대 기간 근거와 2026-06-03 제9회 지방선거의 명시 당선탭/당선표시 존재.
3. 선관위 해당 행의 청주시 선거구와 명부의 현재 선거구가 일치. 비례대표는 선거종류도 확인.
4. 양쪽 출처의 별도 구체적인 경력 또는 학력 문구가 일치. 공백/문장부호·현/전 표기를
   정리한 전체 문구만 비교하며 ‘청주시·충청북도·충북’이라는 명시 지역 접두부 차이만 허용.
   짧은 일반 직함·당명만으로 연결하지 않고 청주시의회/청원군의회 직위 문구는 이 독립 근거에서 제외.
5. 복수 인물 묶음이나 현재 선거구 충돌이 있으면 보류.

예를 들어 최동식 이름의 두 출처는 중국 장춘공업대학 인문정보학원 교수 경력을,
김완식 이름의 두 출처는 상당구 주민복지과장 경력을 명시한다. 현재 선거구와 함께
대조했다. 현/전 표기를 제거하는 이유는 서로 다른 관측 시점의 동일 경력을 연결하기
위함이며 현재도 그 직위를 가지고 있다는 판정이 아니다.

이 연결 범위는 **현재 프로필 ↔ 선관위 선거 사건**이다. 통합 전후·과거 의원 프로필의
영속 인물ID를 병합하지 않았고, 기존 활동 귀속과 집계를 변경하지 않았다.
생년월일 원문은 파생 보고서에 출력하지 않고 선관위 내부 인물 묶음 구분용 해시로만 사용한다.
명부/프로필/선관위 원문 경로·SHA·행/경력항목·정확한 문자 구간을 보존한다.

## 실제 연결 결과와 최소 당선 기록

19명의 현재 프로필에 선거 이력 연결 근거가 충족됐고 25명은 별도 구체적 경력 일치가
부족해 보류됐다. 연결된 선관위 사건 중 확인된 청주·청원 기초의원 당선은26건이다.

| 현재 프로필 | 확인된 당선 기록의 최소 개수 | 확인된 선거일 |
|---|---:|---|
| 김완식 | 2 | 2022-06-01, 2026-06-03 |
| 신민수 | 2 | 2022-06-01, 2026-06-03 |
| 이재숙 | 2 | 2018-06-13, 2026-06-03 |
| 정연숙 | 2 | 2022-06-01, 2026-06-03 |
| 최동식 | 2 | 2018-06-13, 2026-06-03 |
| 홍성각 | 3 | 2018-06-13, 2022-06-01, 2026-06-03 |

위 표는 정확한 전체 선수가 아니라 확인된 당선 기록의 하한이다. 비연속 당선을
포함하며 빈 선거 연도를 낙선·불출마로 추정하지 않는다. 청주·청원 기초의원 지리적
이력이라는 집계 범위를 명시하고 통합의회 내 선수 또는 다른 지역 포함 전체 정치경력으로
확장하지 않는다. 통합 전 경력·재보궐·관측 누락·분석 기준일은 추가 검증 대상이다.

재선 이상 조건의 사전 근거는 참6명·미확정38명이다. 한 건만 보인13명은 초선으로
판정하지 않는다. 자료가 불완전하므로 참을 입증할 수 있는 경우만 참으로 두고,
그 밖은 거짓 대신 null로 둔다. 이 조건은 아직 HTML에 활성화하지 않았다.

결과: `reports/nec-current-profile-links-latest.json`.
모든 행의 `seniority_exact:null`, 완전 선거이력 검증false, 영속 인물 병합0을 유지한다.
현재 의원과의 선거 사건 연결이 성립한19행만 `election_event_link_usable:true`다.

## 자동 검증과 다음 단계

기존3표본 검증과 현재44조회 검증을 구분해 저장하고, 새 연결 검증을 오프라인 가공과
정기수집 게시 전 QA에 연결했다. 후보폴더에 config가 없으면 운영 정의를 전달하되
실제 후보 원문/원장으로 기간을 재검증한다. 원문 해시·조회키 오류는 전건 실패하고,
44조회에서 일부 HTML 구조가 달라진 경우 해당 원문만 보류하며 0건으로 확정하지 않는다.

다음은 보류25명의 추가 독립 근거, 통합 전후/재보궐을 포함한 범위별 완전 경력,
기준일별 당선 횟수와 재임 대수 수의 구분이다. 기존 정책주제/OCR 사람 검토 및
마스터·개인 HTML 조건 연결도 별도 미완료 과제로 유지한다.
