## 3. 안전한 출력 기준과 코드 보강
- 기존 원천 `exports/analyzer/bill_proposers.jsonl` **11,421행**은 원본/호환성용으로만 사용한다.
- 의원 개인별 발의통계는 `exports/analyzer/bill_proposers_member_only.jsonl` **11,377행**만 사용한다.
- `exports/analyzer/bill_proposers_institutional_type_quarantine.jsonl` **44행**은 원본 순서·필드·메타데이터를 유지하는 별도 보존뷰다. **11,377 + 44 = 11,421**.
- 이번에 `scripts/export_analyzer.py`의 분리 함수를 개선했다. **의안 목록의 발의유형과 상세의 발의유형이 동시에 존재하면서 불일치하면, 어느 한 필드가 ‘의원’이더라도 해당 사람 이름을 의원발의 통계에 넣지 않고 격리한다.** 즉 신규 데이터가 들어와도 기관형 값을 다른 표시로 덮어써 통계가 오염되지 않도록 방지한다.
- 회귀검증 `tests/test_safe_bill_proposer_exports.py`에 `의원/시장`, `위원장/의원` 두 방향의 충돌을 모두 격리하는 사례 추가. 현재 2026-11-02 기존 데이터에는 새로운 분할 건수 변화가 없으므로 JSONL·원본 SHA 및 manifest 원형을 유지했다.
- 공식 상세페이지의 ‘대표발의자’ 표기만 보고 기관 발의안의 개인 역할을 `verified_member_proposer`로 자동 승격하는 기능은 **없으며 추가해서도 안 된다**.
