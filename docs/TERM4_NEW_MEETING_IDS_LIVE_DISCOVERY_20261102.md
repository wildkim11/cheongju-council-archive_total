# 제4대 공식 회의록 신규 ID 탐지 및 본문 읽기전용 검증 — 2026-11-02

## 1. 결론

**현재 공식 청주시의회 제4대 회의록 목록은 52건이며, 기존 저장본의 제4대 50건에 없던 `schSn=4024`, `schSn=4025` 두 건을 확인했다.** 두 건 모두 공식 상세페이지의 본문을 정상 수신·파싱했고, 공식 트리에서 `var09=N`인 임시회의록이다. **기존 원본 2,339건의 실제 저장자료·통합 인덱스·분석기 출력은 하나도 변경하지 않았다.**

**검증 범위 한정:** 이번 현황은 1~4대 전체의 최신 목록 전수조회 결과가 아니라, **제4대의 현재 공식 회기/위원회 분기 전부**를 조회하여 저장된 전체 2,339개 ID 세트와 대조한 결과이다. 제1~3대의 신규 ID나 공식 원문 수정은 이 시험으로 확인하지 못한다.

## 4. 추후 안전한 자동수집 전환에 필요한 단계

1. 공식 공개목록에 **새 ID가 있음**과 **그 원문을 읽을 수 있음**은 검증 완료. 기존 저장 스냅샷에 신규 원문을 자동 합치는 **정식 운영 경로**는 아직 미실행.
2. 다음은 2건의 공식 원문을 승인된 작은 범위에서 재조회하여 **기존 2,339건 전체를 임시 복사한 격리 스냅샷에만** 추가하는 시험. 예상 결과는 제4대 52·전체 2,341, 나머지 2,339건의 원문 SHA 불변, Stage C 원장·export 2,341행의 정합성 및 강제종료 복구 확인이다. 이것은 **예상되는 실험 목표**이지 이번에 달성했다고 주장하지 않는다.
3. 원문 재조회 시 이번에 기록한 본문 SHA와 비교한다. 다르면 공식 회의록 내용이 추가로 바뀌었을 가능성이 있으므로 원인 확인 전 자동 적용 금지.
4. 제1~3대에서도 소급 게시·수정이 가능한지 전체 운영 요구에 따라 별도 범위·호출 예산을 검토한다. 이번 제4대 조회를 **전체 2,339건의 공식 실시간 동일성 검사로 확대 해석 금지**.
5. `run_sync("full"/"incremental",ROOT)` 하드 잠금, 자동 스케줄 OFF 유지. 운영 아카이브에 실제 추가·배포하는 일은 사용자 최종 승인 및 격리 검증 뒤에만 수행한다.
