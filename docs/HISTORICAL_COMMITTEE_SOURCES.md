# Historical committee source registry

Historical committee rosters are built from dated official composition/recomposition records.

## Promotion rule

A source record can create relationship membership only when:
- the source is official;
- the roster is explicitly printed in the source;
- committee name and roles can be parsed;
- member names resolve within the source term;
- stated member count matches parsed membership count where a count is printed.

A source that names only chair/vice-chair or only states the committee size remains partial evidence and must not be promoted to a full-roster relationship event.

## Effective periods

Do not infer an end date merely from a later election cycle. Use:
- explicit source dates when printed;
- exact appointment/recomposition dates when supported;
- otherwise preserve an unknown end and let a later verified composition supersede the prior state.

Substitution / reassignment records create a new effective period. Earlier membership is retained.

## Discovery

Candidate source pages are discovered from official committee-activity board listings. Discovery does not itself promote any roster.

The reviewed source registry lives at:
`config/historical_committee_sources.json`
