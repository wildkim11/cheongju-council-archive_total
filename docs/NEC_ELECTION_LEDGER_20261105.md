# 선관위 보존 원문 기반 부분 선거결과 원장 — 2026-11-05

## 완료 범위

`build_nec_election_ledger.py`는 신규 HTTP 요청 없이 SHA/조회키/크기가 검증된 현재44명 이름검색 원문을 재사용한다. 청주·청원 기초의원 관련83개 사건을 보존했고 득표수·공식 표시 득표율67건, 표시 없음16건을 구분했다. 당시에 표시된 정당·선거종류·지역구/비례·선거구·선거일과 원문 경로/해시/문자구간을 함께 보존한다. 득표율 소수점 표기는 문자열로 유지하며 분모와 계산 득표율은 미확정이다.

기존 독립 경력/현재 선거구 검증을 통과한19명의 선관위 인물묶음과 연결되는 사건은30개이며, 당선 표시26개와 결과 미확인 후보 기록4개로 구분한다. 83개 전체를 현재 의원 이력으로 귀속하지 않는다. 현재 프로필과 연결되고 지역구 득표 표시가 있는 기록25개는 제한된 원문 수치 비교의 준비 자료이며 실제 HTML 비교 기능을 활성화한 것은 아니다.

나머지25명은 현재 의회 프로필 경력과 선관위 당선 행의 경력/학력, 명부/현재 선거구/원문 근거를 한 보고서에서 재검토할 수 있도록 묶었다. `identity_review`는 보류 목록이며 새로운 인물 연결·영속ID 병합·정확 선수 확정은 없다. 기존 재선 이상 근거 참6명/미확정38명도 유지한다.

## 상세 수집 준비

원문에 실제 게시된 후보자명부·개표현황·당선인명부·선출 정수·사퇴/무효·무투표 관련 메뉴를 실행하지 않고 URL·함수 인수·상위 data 속성·원문 좌표로 보존했다. 동일한 전체 관측 계약은 한 대상에 묶고 모든 출처 사건과 탭 근거를 남긴다. 총1155개 서로 다른 관측 계약은 **1155개 수집 요청**이 아니며, 실제 양식의 값 매핑/전송방식/선거구 범위를 추가 확인하기 전에는 요청 가능한 URL로 사용하지 않는다.

과거 선거의 ‘역대선거 실시상황’ 링크는 URL secondMenuId `BIGI06`과 함수 인수 `BIGO06`이 달라70개 탭 관측에 불일치가 남아 있다. 원문을 고치거나 임의로 한쪽을 선택하지 않고 두 값을 따로 보존했다. 그 외 과거 선거 공통 electionId `0000000000`도 원문대로 보존한다. 선거일만 보고 다른 ID를 만들어 넣지 않는다.

## 보류하는 계산

- 득표 미표시는 0표·무투표·낙선의 근거가 아니다. 비례에 표시된 수치도 개인 지역구 득표로 전환하지 않는다.
- 전체 후보 명부·정수·당선 경계가 검증되지 않아 순위/당락 표차/선거구 완전성은 미확정이다. 이름검색으로 보인 일부 당선자를 전체 명부로 취급하지 않는다.
- 의회 대수는 공식 대응 근거를 별도로 확보하기 전 자동 기입하지 않는다. 선거회차와 의회 대수를 같은 값으로 쓰지 않는다.
- 원장 생성, 상세 전송경로 확인, 선거구 전체 수집, 지표 검증, 화면 연결은 별도 완료 상태다. 공약 수집·이행평가도 계획 단계로 유지한다.

## 검증과 운영

11개 추가 시험은 누락/공식0/비례/비정상 수치/원문 변경/외부 URL/탭·인물 귀속/메뉴 불일치 보존/동일 관측 계약 재사용/사건별 보류 및 실제 원문 범위를 검증한다. 로컬 전체660개 시험 중659개 통과, 한국어 OCR 모델 의존1개 제외.
오프라인 가공 workflow와 정기수집 게시 전 QA에 생성기를 연결했다. 신규 선관위 정기조회나 수집 스케줄 변경은 없다. 생성 결과는 `reports/nec-election-observations-latest.json`.

다음 단계는 실제 공개 상세 메뉴의 전송 규칙을 제한된 macOS 조회로 확인하고, 선거·선거구 단위의 전체 후보·득표 원문을 중복 없이 확보하는 것이다. 보류25명은 독립 출처의 구체적 학력/경력 근거를 추가 확보하기 전 계속 보류한다.
