## Public records and images

The code license does not automatically apply to:
- official meeting-record text
- member biographies
- official portrait images
- attached documents
- source-site HTML or other public-record content

For these materials, retain the official source URL, source identifier, collection timestamp, and applicable source terms.

Only one official profile portrait per person is intended to be mirrored as a representative image. Other large attachments are referenced by official URL instead of being copied by default.
