# cheongju-council-archive_total

Structured public-record archive for downstream local analysis.

## Scope

This repository is designed to preserve machine-readable source records, version history, source links, and validation metadata. It does not produce political rankings, scores, predictions, or evaluative labels.

Primary source families:
- meeting records
- member profiles and official portrait images
- tenure / party / district / committee membership histories
- bill and resolution metadata
- source links for attachments and official pages

Large attachment binaries are not mirrored by default. Their official URLs and identifiers are retained instead.

## Development status

Foundation work is developed on `feature/archive-foundation`.
Scheduled collection remains disabled until schema and collector validation pass.
